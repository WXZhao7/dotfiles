## 状态栏印象

- `waybar`：性能好、稳定，功能够用。
- `ironbar`：简单直接。
- `eww` / `ags`：适合高度自定义。
- `ashell`：现成可用。
- `Wayle`：可以通过 UI 编辑配置。
